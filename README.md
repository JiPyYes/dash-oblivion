DASH - Dashboard KPI System

- О проекте

DASH — это веб-приложение для визуализации ключевых показателей эффективности (KPI) компании. Система позволяет отслеживать основные бизнес-метрики, анализировать динамику показателей и получать детализированную информацию по финансовым и коммерческим данным.

Проект разработан в рамках учебной практики студентов.

---




- Основной функционал

--- Обзор

* отображение ключевых KPI;
* карточки показателей с цветовой индикацией;
* быстрый доступ к основным разделам системы.

--- Финансы

* графики выручки, расходов и прибыли;
* анализ финансовых показателей;
* визуализация динамики за выбранный период.

--- Продажи

* выполнение плана продаж;
* анализ сделок;
* показатели конверсии;
* работа с фильтрами и выборками.

--- Клиенты

* количество новых клиентов;
* статистика по клиентской базе;
* средний чек;
* анализ активности клиентов.

--- Дополнительные возможности

* адаптивный интерфейс;
* фильтрация данных;
* экспорт отчетов;
* авторизация пользователей;
* сохранение пользовательских настроек.

- Установка проекта

--- Клонирование репозитория

_bash
git clone https://github.com/your-username/dashboard-project.git
_

--- Переход в директорию проекта

_bash
cd dashboard-project
_

--- Установка зависимостей

_bash
npm install
_

--- Запуск проекта

_bash
npm run dev
_

После запуска приложение будет доступно по адресу:

_text
http://localhost:5173
_
